Alowish exposes four closely related endpoints for spatial health intelligence: one to fetch the current environmental snapshot at a named destination, one to compare risk across alternative routes between two points, one to discover health services near any coordinate, and one to initiate a telemedicine consultation for a traveler who needs specialist advice remotely. Together they give you everything you need to present a traveler with not only a risk score, but also a full picture of the environment they are traveling through, the medical resources available along the way, and a direct path to professional medical guidance when needed.

---

## GET /v1/destinations/{id}/conditions

Retrieve the current environmental conditions for a specific destination by its Alowish destination ID. The response includes weather data, air quality, altitude, and a seasonal risk indicator that captures how environmental conditions at this location compare to the same time in past years.

### Path Parameters

<ParamField path="id" type="string" required>
  The Alowish destination identifier. You can find destination IDs in the responses from the risk assessment endpoint or by searching the destination index via the Alowish dashboard.
</ParamField>

### Response Fields

<ResponseField name="location" type="object">
  Geographic metadata for the destination.

  <Expandable title="location fields">
    <ResponseField name="location.name" type="string">Human-readable place name.</ResponseField>
    <ResponseField name="location.lat" type="number">Latitude in decimal degrees (WGS 84).</ResponseField>
    <ResponseField name="location.lng" type="number">Longitude in decimal degrees (WGS 84).</ResponseField>
    <ResponseField name="location.altitude" type="number">Altitude in metres above sea level.</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="weather" type="object">
  Current meteorological conditions at the destination.

  <Expandable title="weather fields">
    <ResponseField name="weather.temperature" type="number">Ambient temperature in degrees Celsius.</ResponseField>
    <ResponseField name="weather.humidity" type="number">Relative humidity as a percentage (0–100).</ResponseField>
    <ResponseField name="weather.wind_speed" type="number">Wind speed in kilometres per hour.</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="air_quality" type="object">
  Current air quality data at the destination.

  <Expandable title="air_quality fields">
    <ResponseField name="air_quality.aqi" type="number">Air Quality Index (0–500, US EPA scale).</ResponseField>
    <ResponseField name="air_quality.category" type="string">Plain-language AQI category, for example `"Good"`, `"Moderate"`, or `"Unhealthy"`.</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="seasonal_risk" type="number">
  A 0–100 indicator of how this destination's current conditions compare to its historical seasonal baseline. A value above 70 means conditions are significantly worse than average for this time of year.
</ResponseField>

## GET /v1/routes

Compare travel health risk across all viable route types between an origin and destination, broken down by waypoints. This is the endpoint to use when you want to present a traveler with a risk-ranked selection of routes — for example, showing that a scenic mountain route carries higher altitude risk than a motorway alternative.

### Query Parameters

<ParamField query="origin_lat" type="number" required>
  Latitude of the journey origin in decimal degrees.
</ParamField>

<ParamField query="origin_lng" type="number" required>
  Longitude of the journey origin in decimal degrees.
</ParamField>

<ParamField query="dest_lat" type="number" required>
  Latitude of the destination in decimal degrees.
</ParamField>

<ParamField query="dest_lng" type="number" required>
  Longitude of the destination in decimal degrees.
</ParamField>

<ParamField query="profile_id" type="string" required>
  The traveler's health profile ID. Without a profile, the API returns aggregate risk scores rather than personalized ones.
</ParamField>

### Response Fields

<ResponseField name="routes" type="array">
  An array of route objects, one per viable route type.

  <Expandable title="Route object fields">
    <ResponseField name="routes[].type" type="string">
      The route type label, for example `"Train"`, `"Motorway"`, or `"Scenic"`.
    </ResponseField>
    <ResponseField name="routes[].risk_score" type="number">
      The overall personalized risk score (0–100) for the entire route.
    </ResponseField>
    <ResponseField name="routes[].waypoints" type="array">
      An ordered list of key waypoints along the route.

      <Expandable title="Waypoint object fields">
        <ResponseField name="waypoints[].name" type="string">Human-readable waypoint name.</ResponseField>
        <ResponseField name="waypoints[].lat" type="number">Latitude in decimal degrees.</ResponseField>
        <ResponseField name="waypoints[].lng" type="number">Longitude in decimal degrees.</ResponseField>
        <ResponseField name="waypoints[].altitude" type="number">Altitude in metres above sea level.</ResponseField>
        <ResponseField name="waypoints[].risk_score" type="number">Individual risk score at this waypoint (0–100).</ResponseField>
        <ResponseField name="waypoints[].nearest_hospital" type="string">Name and approximate distance of the closest hospital to this waypoint.</ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## GET /v1/services/nearby {#nearby-services}

Locate health services and traveler-relevant amenities near any coordinate. Use this endpoint to help travelers identify hospitals, pharmacies, restaurants (relevant for dietary restrictions), and telemedicine providers before or during their journey.

### Query Parameters

<ParamField query="lat" type="number" required>
  Latitude of the search centre in decimal degrees.
</ParamField>

<ParamField query="lng" type="number" required>
  Longitude of the search centre in decimal degrees.
</ParamField>

<ParamField query="radius_km" type="number">
  Search radius in kilometres. Defaults to `10`. Maximum value is `100`.
</ParamField>

<ParamField query="types" type="string">
  A comma-separated list of service types to include in the results. Omit to return all types.

  Supported values: `hospital` · `pharmacy` · `restaurant` · `telemedicine`
</ParamField>

### Response Fields

<ResponseField name="services" type="array">
  An array of service objects within the specified radius, sorted by distance ascending.

  <Expandable title="Service object fields">
    <ResponseField name="services[].type" type="string">Service category: `"hospital"`, `"pharmacy"`, `"restaurant"`, or `"telemedicine"`.</ResponseField>
    <ResponseField name="services[].name" type="string">Name of the service or facility.</ResponseField>
    <ResponseField name="services[].lat" type="number">Latitude of the facility.</ResponseField>
    <ResponseField name="services[].lng" type="number">Longitude of the facility.</ResponseField>
    <ResponseField name="services[].distance_km" type="number">Distance from the search centre in kilometres.</ResponseField>
    <ResponseField name="services[].specialties" type="string[]">List of medical specialties or service sub-types offered (for example, `["cardiology", "emergency"]`).</ResponseField>
    <ResponseField name="services[].rating" type="number">Average user rating on a 1.0–5.0 scale.</ResponseField>
  </Expandable>
</ResponseField>

## POST /v1/telemedicine/consult — Request a Telemedicine Consultation

When a traveler's risk score indicates significant health concern, or when they need expert advice before or during a trip, you can initiate a telemedicine consultation request on their behalf. This endpoint matches the traveler with an available specialist based on their preferred specialty and urgency level, and returns a video consultation link valid for 24 hours.

### Endpoint

```http
POST /v1/telemedicine/consult
```

### Request Body

<ParamField body="user_id" type="string" required>
  The identifier of the user requesting the consultation. This may be an Alowish `profile_id` or your own external user ID if you have linked profiles.
</ParamField>

<ParamField body="destination" type="string" required>
  The name or Alowish destination ID of the location where the traveler will be. Used to match specialists who have knowledge of health conditions prevalent in that region and to account for time-zone scheduling.
</ParamField>

<ParamField body="preferred_specialty" type="string" required>
  The medical specialty most relevant to the traveler's concern. Accepted values: `"general"`, `"cardiology"`, `"respiratory"`, `"endocrinology"`, `"neurology"`, `"oncology"`, `"nephrology"`, `"psychiatry"`, `"allergy"`, `"obstetrics"`, `"rheumatology"`, `"geriatrics"`.
</ParamField>

<ParamField body="urgency" type="string" required>
  How quickly the consultation is needed. Accepted values: `"routine"` (within 48 hours), `"soon"` (within 4 hours), `"urgent"` (within 30 minutes). Urgent consultations incur an additional fee on applicable plans.
</ParamField>

<ParamField body="notes" type="string">
  Optional free-text notes from the traveler describing their concern. Providing context here helps the specialist prepare before the consultation begins.
</ParamField>

### Response Fields

<ResponseField name="consult_id" type="string">
  A unique identifier for this consultation request. Use it to track status or cancel the consultation via the Alowish dashboard.
</ResponseField>

<ResponseField name="specialist" type="object">
  Details of the matched specialist.

  <Expandable title="specialist fields">
    <ResponseField name="specialist.name" type="string">Full name of the assigned specialist.</ResponseField>
    <ResponseField name="specialist.specialty" type="string">Medical specialty of the assigned specialist.</ResponseField>
    <ResponseField name="specialist.credentials" type="string">Abbreviated credentials, for example `"MD, FACC"`.</ResponseField>
    <ResponseField name="specialist.languages" type="string[]">Languages the specialist can consult in.</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="join_url" type="string">
  A secure HTTPS URL the traveler can open in any supported browser to join the video consultation. The link is valid for **24 hours** from the time of this response.
</ResponseField>

<ResponseField name="scheduled_at" type="string">
  ISO 8601 timestamp of the scheduled consultation start time. For `urgent` requests, this is typically within 30 minutes of the API call.
</ResponseField>

<ResponseField name="status" type="string">
  Current status of the consultation request. Values: `"scheduled"`, `"in_progress"`, `"completed"`, `"cancelled"`.
</ResponseField>

### Example

<CodeGroup>

```bash curl
curl -X POST https://api.alowish.com/v1/telemedicine/consult \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "prof_cardiac_001",
    "destination": "Athens, Greece",
    "preferred_specialty": "cardiology",
    "urgency": "soon",
    "notes": "Patient has heart failure and is concerned about traveling during the current heatwave."
  }'
```

```javascript JavaScript (fetch)
const response = await fetch('https://api.alowish.com/v1/telemedicine/consult', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.ALOWISH_API_KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    user_id: 'prof_cardiac_001',
    destination: 'Athens, Greece',
    preferred_specialty: 'cardiology',
    urgency: 'soon',
    notes: 'Patient has heart failure and is concerned about traveling during the current heatwave.',
  }),
});

const consult = await response.json();
console.log('Join URL:', consult.join_url);
console.log('Scheduled at:', consult.scheduled_at);
```

```python Python (requests)
import os
import requests

response = requests.post(
    'https://api.alowish.com/v1/telemedicine/consult',
    headers={
        'Authorization': f'Bearer {os.environ["ALOWISH_API_KEY"]}',
        'Content-Type': 'application/json',
    },
    json={
        'user_id': 'prof_cardiac_001',
        'destination': 'Athens, Greece',
        'preferred_specialty': 'cardiology',
        'urgency': 'soon',
        'notes': 'Patient has heart failure and is concerned about traveling during the current heatwave.',
    },
)

consult = response.json()
print('Consult ID:', consult['consult_id'])
print('Join URL:', consult['join_url'])
```

<Warning>
  The `join_url` contains a short-lived authentication token and should be treated as a secret. Do not log it, cache it server-side beyond the consultation window, or expose it to any party other than the intended traveler.
</Warning>

## Code Examples

<CodeGroup>

```bash Get Destination Conditions
curl -X GET https://api.alowish.com/v1/destinations/dest_venice_001/conditions \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```bash Compare Routes
curl -G https://api.alowish.com/v1/routes \
  -H "Authorization: Bearer YOUR_API_KEY" \
  --data-urlencode "origin_lat=48.1351" \
  --data-urlencode "origin_lng=11.5820" \
  --data-urlencode "dest_lat=45.4414" \
  --data-urlencode "dest_lng=12.3202" \
  --data-urlencode "profile_id=prof_abc123"
```

```bash Find Nearby Services
curl -G https://api.alowish.com/v1/services/nearby \
  -H "Authorization: Bearer YOUR_API_KEY" \
  --data-urlencode "lat=45.4414" \
  --data-urlencode "lng=12.3202" \
  --data-urlencode "radius_km=5" \
  --data-urlencode "types=hospital,pharmacy"
```

```javascript JavaScript (fetch)
// Get destination conditions
const conditions = await fetch(
  'https://api.alowish.com/v1/destinations/dest_venice_001/conditions',
  { headers: { Authorization: `Bearer ${process.env.ALOWISH_API_KEY}` } }
).then(r => r.json());

// Compare routes
const params = new URLSearchParams({
  origin_lat: '48.1351',
  origin_lng: '11.5820',
  dest_lat: '45.4414',
  dest_lng: '12.3202',
  profile_id: 'prof_abc123',
});
const routes = await fetch(
  `https://api.alowish.com/v1/routes?${params}`,
  { headers: { Authorization: `Bearer ${process.env.ALOWISH_API_KEY}` } }
).then(r => r.json());

// Nearby services
const servicesParams = new URLSearchParams({
  lat: '45.4414',
  lng: '12.3202',
  radius_km: '5',
  types: 'hospital,pharmacy',
});
const services = await fetch(
  `https://api.alowish.com/v1/services/nearby?${servicesParams}`,
  { headers: { Authorization: `Bearer ${process.env.ALOWISH_API_KEY}` } }
).then(r => r.json());
```

</CodeGroup>
