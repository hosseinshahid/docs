The Alowish partner API gives you programmatic access to the same health risk intelligence engine that powers the Alowish platform. Whether you are building a travel app, an insurance underwriting tool, or a corporate wellness dashboard, you can embed real-time, personalized health risk scoring directly into your product — no medical expertise required on your end.

## Base URL

All API requests target the following base URL:

```
https://api.alowish.com/v1
```

Every request must be made over HTTPS. Plain HTTP connections are rejected.

## Authentication

Every request requires a Bearer token in the `Authorization` header. Obtain your API key from the [Alowish dashboard](https://app.alowish.com/settings/api-keys).

```http
Authorization: Bearer YOUR_API_KEY
```

See the [Authentication guide](/api/authentication) for full setup instructions, key rotation, and security best practices.

## Rate Limits

Your account tier determines how many requests you can make per calendar day. Limits reset at midnight UTC.

| Tier       | Requests / Day | Notes                                      |
|------------|---------------:|--------------------------------------------|
| Free       | 100            | Suitable for development and prototyping   |
| Pro        | 10,000         | Suitable for production applications       |
| Enterprise | Unlimited      | SLA-backed; contact sales for onboarding  |

When you exceed your daily limit, the API returns a `429 Too Many Requests` response. Add retry logic with exponential backoff to handle this gracefully — see the [Troubleshooting guide](/troubleshooting#api-returning-429) for a code example.

## Response Format

Every response body is JSON. Successful responses include the relevant data object directly at the top level. For example:

```json
{
  "risk_score": 74,
  "risk_level": "high",
  "confidence": 0.91
}
```

All timestamps are ISO 8601 strings in UTC. Coordinates are decimal degrees (WGS 84).

## Error Format

When a request fails, the API returns a structured error object so your code can handle failures programmatically:

```json
{
  "error": {
    "code": "invalid_profile_id",
    "message": "No profile found for the given profile_id.",
    "details": {
      "profile_id": "prof_xyz_unknown"
    }
  }
}
```

### HTTP Error Codes

| Status Code | Name                  | When It Occurs                                                             |
|------------:|-----------------------|----------------------------------------------------------------------------|
| `400`       | Bad Request           | Malformed JSON body, missing required fields, or invalid field values      |
| `401`       | Unauthorized          | Missing, expired, or invalid API key                                       |
| `403`       | Forbidden             | Your current tier does not have access to this endpoint or feature         |
| `404`       | Not Found             | The requested resource (profile, destination, webhook) does not exist      |
| `429`       | Too Many Requests     | Daily rate limit exceeded for your tier                                    |
| `500`       | Internal Server Error | An unexpected error occurred on the Alowish side; retry after a short wait |

<Note>
  If you receive a `500` error that persists beyond a few minutes, check the [Alowish status page](https://status.alowish.com) or contact support at support@alowish.com.
</Note>

## Quick Start Example

The following examples show how to call the risk assessment endpoint with a minimal request body.

<CodeGroup>

```bash curl
curl -X POST https://api.alowish.com/v1/risk/assess \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "profile_id": "prof_abc123",
    "destination": {
      "lat": 37.9838,
      "lng": 23.7275,
      "name": "Athens, Greece"
    },
    "travel_date": "2025-08-14T09:00:00Z",
    "transport_mode": "flight"
  }'
```

```javascript JavaScript (fetch)
const response = await fetch('https://api.alowish.com/v1/risk/assess', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    profile_id: 'prof_abc123',
    destination: {
      lat: 37.9838,
      lng: 23.7275,
      name: 'Athens, Greece',
    },
    travel_date: '2025-08-14T09:00:00Z',
    transport_mode: 'flight',
  }),
});

const data = await response.json();
console.log(data.risk_score, data.risk_level);
```

</CodeGroup>
